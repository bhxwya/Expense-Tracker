# Expense Tracker

A modular CLI expense management application built with Python.

Started as a simple CLI and evolved into a structured project using **OOP, modular architecture, JSON persistence, CRUD operations, input validation, exception handling, logging, budgeting, analytics, and automated backups.**

## Features

- Full CRUD expense management
- JSON persistence and automatic backups
- Input validation with Regex
- Search by category, date and amount
- Monthly budgets and spending warnings
- Monthly statistics and category analytics
- Logging and exception handling
